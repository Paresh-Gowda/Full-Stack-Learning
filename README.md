# 💻 Full Stack Learning Journey

Welcome to my Full Stack Learning repository! This repository documents my journey as I learn and explore full stack development. It contains my hands-on practice, experiments, mini projects, and applications that I build while strengthening my understanding of both frontend and backend development.

So far, I have explored HTML, CSS, JavaScript, Node.js, APIs, PostgreSQL, and Authentication & Security. Each section represents concepts I have learned and practiced, along with the code and exercises I worked on to understand how different parts of a full stack application come together.

This repository will continue to grow as I learn new technologies, build more projects, and improve my development skills. My goal is to keep everything organized in one place and use this repository as a record of my progress toward becoming a Full Stack Developer.
